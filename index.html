Notes on this data: Sourced from separate Director's Report exports for each building ("RSG Guest Count"), academic years 2023–24 through 2025–26. This report includes only Recognized Student Group bookings — administrative bookings are not part of this dataset — and reflects confirmed reservations. The 2023–24 export does not include an organization name field, so those 403 bookings cannot be classified as Religious / Community Impact / Other and appear as "Unclassified"; sub-group trends before 2024–25 should be read with that gap in mind. Guest count is used throughout since that is the attendance field provided in these exports.
